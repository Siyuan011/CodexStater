# 本地后台巡检

双击“scripts_cmd/install-monitor.cmd”。程序自动寻找 Python，约一分钟后首次运行，随后默认每小时一次。无需手动输入命令。Windows 任务名为 Codex-Local-Usage-Hourly，重复安装更新同名任务，不新增重复任务。

采样程序是 src/monitor/local_monitor.py，使用独立账号接口 account/rateLimits/read，不调用模型、不发送提示词。额度查询需要联网及有效 Codex 登录；失败仍采集本机日志用量。首次安装于无历史数据目录时建立基线，不回填历史新增 Token。

## 配置

面板与巡检共用 config/config.json；首次入口自动从 config/config.example.json 创建。相对路径均以仓库根目录为基准。

- codex_root：.codex 路径；空值使用 CODEX_HOME 或当前用户的 .codex。
- data_dir：采样数据目录，默认 data。
- quota_dir：面板读取额度的目录，默认 data；改变 data_dir 时一并改为同一路径。
- logs_dir：运行状态和错误目录，默认 logs。
- cache_dir：面板增量缓存，默认 cache/dashboard；采样缓存为 cache/monitor。
- export_dir：双击导出的报告目录，默认 exports。
- monitor_interval_minutes：巡检间隔，默认 60，范围 5–1440 分钟；修改后再次双击安装入口生效。

修改其他路径后重启面板；巡检下次运行读取新配置。迁移数据目录前暂停巡检，并保留 data 和 cache/monitor 配套数据，避免重复计数。

## 管理与故障

双击“查看巡检状态”查看上次退出码、下次时间以及 logs/local-monitor-status.json。退出码 0 为成功，1 为警告或失败；详细错误见状态和 logs/quota-errors.jsonl。错误仅落地本机，没有模型通知。

“暂停/恢复后台巡检”控制调度；“卸载后台巡检”删除任务但保留历史。暂停不会中断已开始的采样，迁移前需确认任务不在运行。

电脑需开机且用户已登录，可关闭 Codex 界面；关机/注销期间不能采样，恢复后补一次，不补造历史额度。无需管理员权限或保存密码，但公司策略可能限制计划任务，请联系 IT。

Python 查找失败时安装 Python 3.9+，或设置 STATER_PYTHON 指向 python.exe。后台需要同目录的 pythonw.exe。Codex 程序从 PATH 或当前用户安装目录寻找。

独立接口未返回 accountId 时记录为空，不能可靠自动判断账号切换。本机日志计数不能直接换算订阅额度或费用。
